# Js_NotFlappyBird

A JavaScript based ~Flappy Bird~ script. As a script developed during a club meeting it's not very complicated and is meant to be more of a "Hey cool" program than a serious, developed project.

---

## Usage

I recommend copying the script from the main file and pasting it into your JS IDE. This script is simple and silly, so have fun with it and don't be afraid to mess around with the code.
